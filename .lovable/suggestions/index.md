# Suggestions Source Index

**Version:** 0.6.0
**Last updated:** 2026-07-15

Verbatim archive of user suggestions. The tracker at `.lovable/suggestions.md` references entries here by ID.

## Conventions

- One file per suggestion: `sug-NNN-slug.md`.
- Store the user's exact wording under a `## Verbatim` heading. Do not paraphrase.
- Include: capture date, source (chat turn or file), status (pending/implemented/rejected), and a link back to the tracker row.
- Never edit historical verbatim text after capture. Corrections go in a new entry.
