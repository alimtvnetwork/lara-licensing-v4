# Newline Styling Conventions

As per the coding guidelines (`spec/13-generic-cli/08-code-style.md`), we must strictly enforce newline styling across the codebase.

## Return Statements
- **Rule:** There must ALWAYS be a blank line before a `return` statement.
- **Exception:** Unless `return` is the only statement inside an `if` block.

This rule applies to both TypeScript (frontend) and PHP (backend) code.
